VEXON VPN

A modern, secure, and minimalist VPN platform for Android and iOS.

VEXON VPN is a cross-platform VPN project focused on a clean user experience, reliable connections, and simple subscription management.

Features

- Modern, minimalist interface
- Single-screen dashboard without scrolling
- Custom animated connection button
- Connect and disconnect controls
- Server selection and connection status
- Personal V2Ray configuration import
- Configuration import through text, file, or QR code
- Subscription activation using a code
- QR code generation for subscriptions
- Support for single-device and three-device plans
- Dedicated administration panel
- Server health monitoring
- No advertisements

Platforms

- Android
- iOS, including iPhone 17

Project Components

1. Mobile Application — User interface, VPN connection controls, server selection, and configuration management.
2. VPN Infrastructure — VPN servers and connection protocols.
3. Administration Panel — Subscription creation, activation codes, QR codes, and user management.
4. Backend API — Subscription validation, server information, and device limits.
5. Download Website — Application information and Android APK distribution.

Technology

The project will use suitable open-source technologies where possible. Platform-specific VPN integration will be implemented according to Android and iOS requirements.

Development Status

Status: Planning and initial development.

Features will be marked as complete only after implementation and testing.

Security

- Secure communication between the application and backend
- Server-side subscription validation
- Protection against repeated activation attempts
- Secure handling of VPN configurations
- Device limits enforced by the backend

Infrastructure

The software is intended to use cost-effective infrastructure where available. Actual server capacity, bandwidth, and operating costs depend on provider limits and real-world usage.
